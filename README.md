# Advent of Code 2024 — Python Solutions

This repository contains my Python solutions to puzzles from [Advent of Code 2024](https://adventofcode.com/2024).

## Purpose

- Practice Python through programming puzzles
- Improve problem-solving and algorithmic thinking
- Keep solutions organized for later review

## Structure

Solutions are organized by day. Each file corresponds to a puzzle day.

## Running a Solution

Run a solution with Python 3 from the repository directory. For example:

```bash
python <solution-file>.py
```

The exact filename and any input-file requirements depend on the individual solution.

## Notes

This is a personal learning repository. Solutions may be revised as I revisit problems and explore alternative approaches.
